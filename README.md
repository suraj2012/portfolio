# Suraj Kawale - Portfolio

React + Vite + Tailwind CSS v4 + Framer Motion.

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # production build in dist/

Edit your content in `src/data.js`. Replace `public/suraj.jpg` and `public/Suraj_Kawale_Resume.pdf` to update photo and resume.
